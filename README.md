# Gurprince Singh — Portfolio

Personal portfolio of Gurprince Singh, full stack developer in Mohali, Punjab.

Built with React + Vite, animated with GSAP (ScrollTrigger) and smooth-scrolled with Lenis.

## Run locally

```bash
npm install
npm run dev
```

`npm run build` outputs a static site to `dist/`, ready for Vercel, Netlify or GitHub Pages.

## Editing content

All text (projects, experience, skills, contact) lives in `src/data/resume.js`.
Project screenshots are in `src/assets/projects/`, tech logos in `src/assets/logos/`.
The downloadable résumé is `public/Resume_Gurprince_Singh.pdf`.
